# PenReso（ペンレゾ）ダウンロード
CLIP STUDIO PAINTでのペンの動きや筆圧に音を添えるWindows向け作画サポートアプリです。

## 最新版
[0.5.2-preview.4・無料試験版](https://github.com/jin-plus-humor/penreso-downloads/releases/latest)のAssetsからPenReso-0.5.2-preview.4-windows.zipを取得してください。Source codeはアプリ本体ではありません。GitHubアカウントやGitのインストールは不要です。
加工済みGペン音源を同梱。音色はGペン標準・低音・明瞭と自分の音源の4項目です。

## 起動・更新
ZIPを全部展開し、PenReso.exeを開きます。「ペンレゾを登録.exe」からスタートメニューへ登録すると、PenReso・ペンレゾ・ぺんれぞで検索できます。
旧版は「終了」で完全に終了してください。新しいフォルダーの「ペンレゾを登録.exe」から「以前の音源・設定を引き継ぐ」を押し、旧版のbinを選びます。元データと移行前バックアップは保存します。起動後の画面バージョンと試聴を確認してください。
自動更新はありません。個人設定や追加音源はZIPに含みません。

## 環境・制限
Windows 10/11 x64、.NET Framework 4.8、CLIP STUDIO PAINT、Wacomドライバーと登録した対応タブレットが必要です。Mac・iPad版はまだありません。
Bluetooth固有の遅延は残る場合があります。低遅延設定は内部キューを短くする比較用設定で、遅延解消を保証しません。低スペックPC・電池消費は未検証です。
